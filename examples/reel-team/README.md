# 릴스 팀 데모

Claude Code 서브에이전트 8명이 AI 호스트 릴스를 하나씩 맡고, 끝나는 대로 결과물 영상을 모니터에 올리는 데모입니다.
훅·서버·화면은 실제로 돌아가는 그대로입니다. 영상 생성 단계만 미리 만든 편집본으로 대신합니다(재현 모드).

## 준비

```bash
# agent-monitor 폴더에서
python3 start.py --open        # 아이패드에 띄우려면 --lan
```

`media/` 에 `1_minji.mp4` … `8_yerin.mp4` 처럼 `<번호>_<이름>.mp4` 로 영상을 넣어 두면 그 파일이 결과물로 뜹니다.
영상은 저장소에 들어 있지 않습니다. 넣지 않으면 로봇과 이름표, 결과 한 줄까지만 뜹니다.
영상이 인터넷에 있으면 `hosts.json` 의 호스트에 `"remote": "https://…/파일.mp4"` 를 적어 두면 처음 실행할 때 내려받습니다.

## 실제 에이전트로 돌리기

```bash
cd examples/reel-team
claude
```

Claude Code 안에서:

```
/reels
```

`/reels 1` 처럼 번호를 주면 그 호스트만, `/reels 2 5 7` 이면 세 명만 돌립니다.

1. 총괄 세션이 `릴스 PD` 이름표를 달고 들어옵니다.
2. `reel-host` 서브에이전트 8명이 동시에 들어오고, 각자 자기 호스트 이름표를 답니다.
3. 정해 둔 시간이 지나면 한 명씩 "결과물 나왔어요" 하고 타일에 자기 릴스를 띄웁니다.
4. 8명이 다 끝나면 PD가 "끝남"이 되고 재촉을 시작합니다. 타일을 누르거나 **모두 확인**을 누르면 조용해집니다.

처음에 Claude Code가 `python3 make_reel.py` 실행을 허락할지 물으면, 그 명령을 다시 묻지 않게 하는 선택지를 고르세요.
안 그러면 서브에이전트마다 한 번씩 묻습니다. 묻는 동안 그 타일은 "승인 필요"로 바뀌고 실행하려는 명령이 뜹니다.

서브에이전트는 `.claude/agents/reel-host.md`, 명령은 `.claude/commands/reels.md` 에 있습니다. 서브에이전트 모델은 빠른 haiku 입니다.

## 어떻게 화면에 뜨나

`make_reel.py` 가 출력하는 두 가지를 agent-monitor 훅이 읽습니다.

| 출력 | 모니터에서 |
|---|---|
| `[agent-monitor] name: 홈트 서윤` | 이 일을 하는 에이전트 타일의 이름표 |
| `[agent-monitor] text: 홈트 서윤 릴스 완성 · 5.2초 · 1080×1920` | 타일의 결과 한 줄 |
| `완성: /…/out/3_seoyun.mp4` | 그 파일을 결과물로 타일에 띄움 |

결과물 파일 경로는 이 컴퓨터의 모니터 서버에만 가고, 화면에는 `/media/<임의 id>.mp4` 주소로만 나갑니다.
서브에이전트의 마지막 답에 경로를 적어도 같은 방식으로 뜹니다.

자기 작업에 쓸 때도 똑같습니다. 이미지·영상을 만드는 도구나 스크립트가 결과물의 경로나 주소를 출력하면 그 에이전트 타일에 뜹니다.
이름표를 붙이고 싶으면 `[agent-monitor] name: ...` 한 줄을 출력하세요.

## 에이전트 없이 리허설

```bash
python3 replay.py              # 같은 장면을 모니터 API로 재생
python3 replay.py --speed 3    # 3배 빠르게
```

Claude Code 없이 화면 흐름만 확인할 때 씁니다. 이때 타일 출처는 `Custom` 으로 표시됩니다.

## 촬영 팁

- 주소에 `?hint=0` 을 붙이면 "탭하면 소리가 켜져요" 안내가 안 뜹니다.
- 소리를 켜려면 촬영 전에 화면을 한 번 누르세요.
- 다 끝난 뒤 **혼돈** 모드로 바꾸면 확인 안 한 에이전트가 전부 떠듭니다.
- 결과물은 `out/` 에 남습니다. 지워도 됩니다. `out/` 과 `media/` 의 영상은 저장소에 올라가지 않습니다.
